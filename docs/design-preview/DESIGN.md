# 媒体工作台设计稿

状态：保留的独立交互原型，未接入后台；正式工作台已实现并部署，当前功能以 WEBUI_FEATURE_COVERAGE.md 为准。此目录仅记录设计过程。

## 使用边界

预览入口为本机 `http://127.0.0.1:8084/`，无需登录。资源、频道、任务、进度与路径均明确标注为示例；操作仅改变浏览器内存，刷新后恢复。没有后台 API、外部请求、凭据读取、持久化写入或 NAS 操作。

## 设计结构

- 顶部：产品标识、找资源/追更/频道三个工作区入口、连接状态、设置。
- 主区：搜索栏与频道选择、按需展开筛选、资源比较列表、分页和批量操作。
- 辅区：可收起的下载队列，进行中/已结束筛选，任务详情。
- 追更与频道共用主区的位置；切换保留搜索、筛选和选择状态，队列不离开工作台。
- 资源卡片直接展示季集、画质、编码、来源、大小与下载操作。集数作为醒目的数字标记，完整文件名在详情显示；不接入封面或外部剧集资料。
- 不独立展示 KPI、欢迎横幅或功能宣传；统计只存在于结果计数和队列筛选。

## 视觉系统

石墨黑画布、深灰工作面、荧光青柠操作强调，淡紫季集标记。颜色以功能为中心：青柠用于当前入口、选中、进度和主要操作，紫色帮助识别季集；不使用大面积装饰渐变。统一 10–16px 控件与容器圆角，资源对象以卡片组织，状态辅以文字，不仅依赖颜色。

字体优先本机 Inter/Segoe UI/微软雅黑，不下载字体。正文 16px，主要标题 30px，搜索输入 24px，资源名称 18–20px，画质 16px，来源与季集 14px；12–13px 仅用于辅助提示。主要按钮至少 44px，资源卡片内次级下载按钮 36px。桌面以两列资源卡片比较，超宽屏三列，手机单列。

桌面队列 340–380px，其余空间归资源区；1250px 以下队列移动至主区下方，760px 以下顶部导航换行、卡片单列。桌面资源区按可视高度组织，分页和批量操作位于资源滚动区域之外；窄屏限制结果区域高度，防止无限拉长。

顶部选中背景平滑滑动，工作区与弹窗以 260ms 位移/透明度进入，队列展开使用可中断的 300ms 布局过渡。每次操作先更新真实界面状态，动画不控制正确性；快速连续操作取消旧动画，系统“减少动态效果”偏好禁用动效。没有背景循环动画或每张卡片连续入场。

## Skill 使用依据

已读取 ui-ux-pro-max 主指引、quick-reference 与 pro-rules。本轮深色活力工作区查询命中 Dark Mode (OLED)，采用深色表面、文本对比度和可见焦点规则；自动生成的 FAQ/Documentation Landing 模式、代码向字体组合不适合媒体工具，未套用。青柠与淡紫是本轮视觉选择，不把它们宣称为自动查询推荐。

动效检索命中 Reduced Motion 与 Excessive Motion，限制同时运动元素、适配减少动态效果；筛选按需展开、保留工作区状态和醒目主要操作采用静态规则。不保留不适用的自动生成模板。

实际前端为原生 HTML/CSS/JavaScript，skill 无原生 CSS 专用 stack；不伪称使用 Tailwind，不为设计稿迁移技术栈。图标为本地统一线宽 SVG，所有原型交互与实际业务隔离。

## 后续实现要求

视觉确认后再将布局接入现有搜索、来源记录、任务分页、追更、安全入库和替换接口。正式下载必须保留媒体身份确认及入库目标核对；原型操作不能直接当作正式业务实现。控制台鉴权与 Telegram 授权保持分离。
