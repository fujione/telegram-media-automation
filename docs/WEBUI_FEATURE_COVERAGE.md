# WebUI 功能与页面覆盖

当前工作台已完成 NAS 部署验证（2026-09-30）。设计样例仅保留为历史原型，不能代表当前应用状态。下面记录正式界面与 API 的功能对应。

## 页面结构

2026-10-26：rc2 已上线订阅编辑弹窗及保存冲突后的重新载入入口。可编辑搜索词、季集计划和频道范围；暂停订阅保存后仍保持暂停。

顶部三个日常入口：找资源、追更、频道。主工作区共用位置，下载队列持续可见、可收起；队列的“展开记录”提供宽版任务记录。设置从顶部进入。管理员登录页和首次创建账号页独立于 Telegram 授权。

## 功能对应

| 功能 | 页面入口与行为 | 后台接口 |
| --- | --- | --- |
| Docker首次配置（rc4候选） | 一次性初始化码、本人Telegram API、管理员与偏好；保存后重启 | `/auth/setup` |
| 管理员登录、初始化账号、退出 | 登录页 / 首次设置 / 右上角账号菜单 | `/auth/login`、`/auth/setup`、`/auth/session`、`/auth/logout` |
| 搜索资源 | 找资源：片名、默认频道、临时频道 | `/searches` |
| 画质与语言筛选 | 搜索栏下“筛选与搜索范围”：分辨率、语言、最大大小、HDR；显示全局默认偏好 | `/settings/quality`、`/searches` |
| 资源排序、分页 | 结果区：匹配、季集、大小排序；10/20/50 条每页，结果区限高滚动 | 搜索返回资源，本地分页 |
| 资源信息与来源 | 卡片：季集、画质、编码、大小、来源；点名称查看完整文件名、语言、原消息、转发来源 | `/resources/{id}` 与搜索响应 |
| 下载并自动入库 | 卡片“下载”：确认片名、年份、季集和目标预览；主按钮建立入库计划 | `/media/suggestions`、`/tasks` |
| 多选下载 | 卡片复选框 → 下载所选；逐个核对媒体信息，每个任务单独确认、单独幂等键；取消停止后续确认 | `/tasks` |
| 仅下载 | 下载确认中的次级按钮；完成后留在下载收件箱，任务可手动入库 | `/tasks` 不携带入库计划 |
| 下载后替换已有资源 | 卡片直接“替换”：查找媒体库目标、选择文件、核对季集；下载后自动替换 | `/library/files`、`/tasks` 携带替换计划 |
| 已下载文件入库或替换 | 队列任务详情：入库 / 替换；确认媒体信息与目标 | `/tasks/{id}/import`、`/tasks/{id}/replace` |
| 下载中任务设置替换 | 队列任务详情“设为下载后替换”；支持排队、下载中、暂停、重试中的任务 | `/tasks/{id}/replacement-plan` |
| 查看任务与异常 | 队列：全部、进行中、待处理、已结束；宽版记录、服务器分页、状态与错误详情 | `/tasks/page`、`/tasks/summary` |
| 暂停、继续、重试、取消 | 任务按钮与详情；取消前确认，不删除媒体库文件 | `/tasks/{id}/pause`、`resume`、`retry`、`cancel` |
| 任务时间线 | 任务详情“查看时间线” | `/tasks/{id}/events` |
| 追更与补集 | 追更：创建订阅，设置搜索词、季集、补集与持续追更；从维护列表选择频道，不选则跟随全部已启用默认频道；暂停、恢复、删除 | `/subscriptions` 与订阅动作接口 |
| 频道管理 | 频道：粘贴链接、验证添加，或从已加入频道选择；暂停、恢复、删除 | `/channels`、`/channels/inspect`、`/channels/discover` |
| Telegram 授权 | 正常时只显示顶部连接状态；设置中按状态显示手机号、验证码或两步密码流程 | `/telegram/status` 与登录接口 |
| 运行状态 | 设置：Worker、Telegram、版本、区域、入库策略、维护、追更周期、剩余空间 | `/system/status`、`/health/ready` |
| 立即检查与历史（rc3候选） | 追更卡片：检查请求合并、限流提示、持久扫描历史 | `/subscriptions/{id}/check`、`/subscriptions/{id}/scans` |
| 诊断预览与导出（rc3候选） | 设置：默认脱敏，下载与当前预览一致 | `/diagnostics` |
| 数据库备份 | 设置：创建、列出、下载记录备份 | `/backups` |

表中 API 路径统一以 `/api/v1` 为前缀，健康检查除外。全局配置修改、管理员密码重置、完整备份恢复、单独 worker 仍使用 `mediactl` 与运维文档；页面展示全局设置但不提供不存在的配置写入接口。

## 入库与替换约定

- 正常手动下载在入队前确认媒体身份，携带入库计划；追更自动建立已确认计划。完成下载与文件校验后，后台执行入库。
- 主动“仅下载”不会自动入库；入库失败展示异常，不应显示完成。
- 替换必须明确选择目标并确认身份；后台校验新文件、保留旧文件备份后执行替换。
- 8084 的样例按钮不调用这些接口。正式验证以本地 8083 为准。

## 设计与验证

沿用已确认的石墨黑、青柠、淡紫季集标记与顶部导航，不接入外部封面资料。正文 16px，主标题 30px，资源标题 18–20px。按 `ui-ux-pro-max` 静态规则处理焦点、渐进展开、文本对比度；表单错误检索命中 Focusable Error Summary / Error Messages，将接口错误保留在表单内并播报。动效可取消并适配减少动态效果，状态正确性不依赖动画完成。

自动化验证覆盖后台回归、500 条资源分页、1000 条任务分页、独立入库计划、多选逐项确认、替换目标与替换计划、失败重试幂等性、队列偏好、焦点保留、8 种屏幕宽度、英文界面、网络失败和登录失效。浏览器中的业务写请求用测试响应拦截，不触发真实下载、替换或 NAS 写入。
