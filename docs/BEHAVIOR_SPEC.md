# 行为规格

## 集数解析

| 输入 | 期望 |
|---|---|
| `Show.S01E02.1080p.mkv` | season=1, start=end=2 |
| `Show S02E03-E05` | season=2, start=3, end=5 |
| `Show EP07` | default season, start=end=7 |
| `第十二集` | default season, start=end=12 |
| `第1集至第3集` | default season, start=1, end=3 |
| `01-02集` | default season, start=1, end=2 |
| `全24集` | 无具体集数 |
| `2026 2160p` | 无具体集数 |

解析结果必须携带证据来源和置信度。caption 与 filename 冲突时不能静默选择。

## 候选选择

硬性过滤先于评分：媒体身份、请求集数覆盖、允许语言、文件大小边界。评分按身份可信度、
覆盖完整度、语言、分辨率、HDR、编码、音轨、大小、发布时间和稳定 ID 依次比较。

允许分辨率与允许语言为空表示不做对应硬过滤；非空时，元数据未知的候选也不能通过该
硬过滤。交互搜索可覆盖全局分辨率、语言、大小和 HDR 偏好，但不得改变持久全局配置。

相同最高分且身份不唯一时返回 `needs_selection`。

## 媒体身份建议

- Web 创建任务时可从搜索词生成可编辑的片名、年份和季集建议。
- 季集证据和常见质量标签不得进入建议片名。
- 只有括号或方括号中的年份才自动填入年份，避免把 `Blade Runner 2049` 等片名数字误判。
- 建议不等于确认；自动归档前仍必须由用户勾选确认身份。

## 下载

- 任务先写数据库再进入队列。
- 任务查询支持稳定分页、总数和多状态过滤；分页排序使用创建时间与任务 ID 保证确定性。
- 任务关联的资源可按稳定资源 ID 单独查询，不依赖候选列表的截断窗口。
- 进度写入持久状态，文件写入 `.part`。
- 重启时不得重复创建同一活动 attempt。
- 完成文件必须通过大小校验后才能进入 downloaded。
- pause 后保留 part；resume 从可信偏移继续。
- cancel 后不会因重启恢复；显式 retry 创建新 attempt。

## 归档

- 同卷 move 必须原子完成。
- hardlink 只在源目标同设备时使用。
- 跨卷 copy 需要临时目标、fsync、校验和原子改名。
- 目标冲突不覆盖，等待用户选择。
- imported/provisional 必须对应存在且非零的文件。
