# 实施计划与开发基线

## 产品方向

产品围绕 Telegram 用户账号登录、指定频道搜索、影视候选选择、持久下载、文件归档和
指定电视剧追更，持续完善从资源发现到媒体入库的完整体验。

## 已实现基线

- Python 包、Git 仓库、uv lockfile、CI、Dockerfile 和单服务 Compose。
- FastAPI 双认证（Web 管理员安全 Cookie、自动化 Bearer Token）、liveness/readiness、
  OpenAPI 和产品化响应式 Web 控制台。
- Telethon 用户账号验证码/两步验证登录及持久 Session。
- 指定频道历史搜索、媒体元数据提取、季集解析、质量排序和候选持久化。
- 全局质量策略统一控制交互搜索与自动追更；Web/API 单次搜索可覆盖分辨率、语言、大小和
  HDR 偏好，允许列表执行硬过滤。
- 文件名/说明集数冲突显式展示；自动追更拒绝冲突候选，未来集进入持久积压，已过期、
  季数不符和无法解析的积压会自动清理。
- 可持久配置、暂停、恢复和删除默认搜索频道；单次搜索可临时覆盖作用域。
- SQLite 版本迁移、任务/资源/订阅/频道游标/事件持久化。
- 统一任务状态机、幂等创建、乐观并发、暂停/恢复/取消/重试。
- `.part` 断点续传、大小校验，以及同卷原子移动/跨卷复制校验后进入 inbox。
- 下载无数据超时、磁盘门禁、可选限速、代理与故障分类。
- 电影/电视剧安全归档、冲突保护、内容去重和最终路径记录；归档策略支持移动、同文件
  系统硬链接和校验复制，不做静默降级。
- 指定影视订阅轮询；每订阅、每频道独立游标，只入队下一集。
- 追更采用默认五分钟的周期门控，与下载短轮询解耦；创建/恢复订阅主动唤醒，并阻止
  FloodWait 期间的重复扫描。
- 追更任务携带不可变归档计划，下载校验完成后无需人工介入即可进入电视剧媒体目录。
- 订阅可持久化 `2, 4-6` 等缺集计划，支持“仅补齐后停止”与“先补齐再从下一集继续”，
  补旧集不会倒退连续追更位置。
- 频道输入统一接受完整公开 `t.me` 链接、`@` 用户名、纯用户名、`-100` 数字 ID 和可解析
  的 `t.me/c/...` 消息链接，避免要求用户手工裁剪 Telegram 中看到的链接。
- 默认频道可通过当前 Telegram Session 在保存前解析，Web 使用实体是否存在公开 username
  标记公开/私有，并显示 Telegram 标题，避免让用户按“加入”按钮或链接外观猜测。
- Web 可发现当前 Telegram 账号已加入的频道与超级群，按标题和公开/私有类型提供可直接
  选择的规范标识，私有频道无需用户手工查找内部 ID。
- Web 搜索候选可创建“仅下载”或携带不可变电影/剧集归档计划的任务；任务列表显示资源
  文件、进度、错误和目标媒体库，而不是只显示内部状态。
- 任务队列提供带总数的服务端分页与状态分组筛选；Web 按任务引用逐个补取资源元数据，
  避免任务或资源超过固定列表上限后显示不完整。
- Web 工作台提供完整队列、处理中、需处理和已结束任务统计，可直接进入对应服务端筛选；
  搜索候选与任务使用分层卡片、质量徽章、状态标签和独立错误提示，而非扁平文本罗列。
- 创建任务时从搜索词生成保守的可编辑片名/年份/季集建议，去除质量与集数标签，同时
  保持自动归档的人工确认要求。
- API 与 worker 共用单个 Telethon gateway；SQLite 原子领取任务、持续续租并回收过期 lease；
  worker 一旦失租会中断远端读取并禁止提交文件，跨卷复制在线程中执行以免阻塞续租。
- 本机/Compose 初始化向导支持管理员、语言、IANA 时区、自定义状态/下载/媒体目录和
  落盘前写入验证；Compose 将各宿主机目录映射到固定容器路径。
- 中文/英文登录页与控制台运行时本地化；任务事件和备份时间按配置 IANA 时区显示，
  认证前端点只公开语言与时区。
- 带 SHA-256 校验的 CLI/Web 数据库备份。
- `mediactl doctor` 启动前自检，覆盖密钥、Telegram/代理配置、数据库版本、worker、
  目录实际写入权限与磁盘余量，并支持 JSON 输出和失败退出码。
- Web 管理员密码使用带盐 `scrypt` 哈希；会话采用 HttpOnly/SameSite Cookie、CSRF 防护、
  登录限流，且重置密码会使旧会话失效。
- 内部管理 Token 原子轮换、启动端口占用预检，以及可配置的 Telegram 连接重试和 API
  硬超时。
- 文件维护循环按保守保留期清理可证明归属的已取消/孤立 part 和提交临时文件；
  保留可恢复任务文件、跳过普通文件，并限制 NAS 媒体库扫描深度。

## 质量门禁

每次合并必须通过：

```powershell
uv sync --locked --all-extras
uv run ruff format --check .
uv run ruff check .
uv run mypy
uv run pytest --cov=telegram_media_automation --cov-report=term-missing
```

真实 Telegram 验证依赖用户自己的 API ID、API Hash、手机号、验证码和可访问频道，不在
自动化测试中保存任何凭据或 Session。
